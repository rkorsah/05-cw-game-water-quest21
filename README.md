# Clean Water Quest

A small, responsive browser game inspired by charity: water. Flip tiles to find clean water drops, avoid pollution, and reach the 10-drop goal.

## How to play

1. Choose any covered tile to reveal what’s inside.
2. A clean water tile adds one drop to your score. A pollution tile takes away up to two drops.
3. When all nine tiles are revealed, a fresh set appears. Reach 10 drops to win.
4. Select **Start over** at any time to reset the score and start a new game.

The game runs in the browser and does not require an account or save personal information. Open `index.html` to play.
